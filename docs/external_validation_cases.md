# External validation cases — model v2

The following places are treated as **validation hypotheses**, not hand-selected winners. The purpose is to test whether an independently constructed public-data model can explain known market interest while still surfacing non-obvious alternatives.

- **São Gonçalo do Amarante / Pecém (CE)** — ranks #1 in provisional no-water Hyperscale AI and Colocation. Strong market validation, but EPE near-term access-risk evidence remains a first due-diligence gate.
- **Fortaleza (CE)** — connectivity benchmark with the strongest observed ANATEL provider count, but #48 Hyperscale AI. This is desirable: submarine/fibre strength does not automatically override climate, energy, environmental and grid factors.
- **Parnaíba (PI)** — #6 Colocation but #45 Hyperscale; ZPE/planned-grid-expansion context makes it highly scenario-sensitive rather than universally dominant.
- **Cabo de Santo Agostinho / Suape (PE)** — #3 Colocation but #43 Hyperscale and #94 Renewable-first, consistent with an industrial/logistics hypothesis rather than a renewable-resource leader.
- **Lajes (RN)** — #6 Hyperscale and #5 Renewable-first despite no strategic/ZPE bonus. This is an important non-obvious challenger and evidence that the model is not simply copying investment announcements.
- **Camaçari (BA)** — #132 Hyperscale; strong grid/connectivity alone do not compensate for weaker energy-resource evidence in the current model.
- **Bacabeira (MA)** — #277 Hyperscale; remains a longer-term ZPE watchlist rather than a leading technical candidate.

All ranks are provisional because water is not yet scored, grid headroom is unverified, and the CNUC geometry still needs the July-2026 refresh.
